# Shot, Over!

**Shot, Over!** makes crewing the M101 howitzer of S.O.G. Prairie Fire a gunline job: carry the shells, set the charge, load the breech by hand, and work out the firing data in the FDC notebook.

Shot, Over! was created by YannikH and toadball of the original ITC team (with Yax) and never released. This version continues it; YannikH invited that in [itc-addons/ITC_Land_Systems#24](https://github.com/itc-addons/ITC_Land_Systems/issues/24). The original code is at [YannikH/Shot-Over](https://github.com/YannikH/Shot-Over).

The project is entirely open-source and any contributions are welcome.

!!! info "Requirements"
    Shot, Over! requires [CBA_A3](https://github.com/CBATeam/CBA_A3/releases/latest), [ACE3](https://github.com/acemod/ACE3/releases/latest) and the [S.O.G. Prairie Fire](https://store.steampowered.com/app/1227700/) CDLC.

## Features

- M101 howitzer loaded by hand
- Shells, crates and pallets
- FDC notebook
